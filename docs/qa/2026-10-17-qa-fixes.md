# QA findings and fixes · 2026-10-17

All 11 major findings from the [QA report](2026-10-17-qa-report.md) are fixed, one commit each. Each fix has an automated check (for logic) or a browser check (for UI). After all fixes: `npm run check` (13 files), `npm test` (30 tests), both type checks, lint and `next build` (251 pages) pass.

## Major findings

| # | Finding | Fix | Commit | How it was checked |
|---|---|---|---|---|
| 11 | Scoring was O(n²): 16 ms per cold ranking at 239 laptops, 266 ms at 1,000 | `percentiles()` sorts once and binary-searches each value's run of equals (O(n log n)) | `559118f` | New check: matches brute force on 500 values with ties, and 10k values in under 100 ms (failed before). Identical rankings on 108 briefs over the real catalog |
| 9 | Duplicate config chips: MacBook Air 13 M5 showed "16 · 512" twice and hid the 8- vs 10-core GPU | Chip uniqueness counts distinct configs. Exact duplicates share one chip.
