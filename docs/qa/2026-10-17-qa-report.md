# FITLAP QA report · 2026-10-17

Target: production https://fitlap.vercel.app, build 2026-10-16T13:54Z, 239 laptops, 504 configs. Five parallel Opus 5.5 agents covered E2E journeys, data correctness, responsive layout, accessibility, and performance/load. Findings marked ✓ were re-checked against the code, the live site or the extracted catalog.

**Bottom line:** no blockers. The core works: scoring in the UI matches a Node re-run on 12 of 12 briefs, and hard filters had 0 violations across 19 briefs. All journeys pass with 0 console errors. Most problems are in data quality, light-theme contrast, the advanced brief on phones, and semantics.

## Passed

- Journeys: landing (demo cycling, FAQ, CTAs, course link, /legal), brief simple and advanced, results (rail, config switcher, compare picker max 4, Esc), details (all views, `?cfg=`), compare (add/remove, differences only, bad codes cleaned), shared links, restore from storage, back/forward, theme persistence, `/laptop/does-not-exist` 404.
- Correctness: 12/12 briefs match Node on the full rail (count, order, fit, config, price). 19 briefs, 0 hard-filter violations. Breakdown rows sum to fit. Orange screen at ≥ 80 correct on 168 cards. PriceDelta tiers correct. Compare labels and best-in-row match Node. 64 URL codec round trips, 0 failures.
- Responsive: simple-mode pages have no overflow at any of 11 viewports. Compare modal fits and scrolls everywhere. Drawings stay visible on dark panels.
- A11y: `lang`, names on all controls, no duplicate ids, logical tab order, no keyboard traps, visible focus everywhere, native dialog focus handling, aria-pressed/expanded states, reduced-motion rule. Dark theme passes contrast.
