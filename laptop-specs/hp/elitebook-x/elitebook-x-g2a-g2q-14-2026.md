# HP EliteBook X G2a 14 / X G2q 14 (2026)

Premium 14" 16:10 ultrabook from about 1.05 kg with on-package LPDDR5x up to 64 GB, Wi-Fi 7 and optional 5G. The X G2a uses AMD Ryzen AI PRO 400 (Gorgon Point, Radeon 800M graphics). The X G2q uses Qualcomm Snapdragon X2 Elite or X2 Plus (Windows on Arm). G2a data is from HP's support specification page. G2q data is from the HP QuickSpecs. Weight and dimensions for the G2a are from Notebookcheck.
