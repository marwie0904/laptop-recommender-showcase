# HP ZBook 8 G2i 16 / G2a 16 (2026)

Second generation of HP's entry 16" ZBook 8, replacing the G1i 16. G2i uses Intel Core Ultra series 3 (Panther Lake) with optional NVIDIA RTX PRO 500 Blackwell. G2a uses AMD Ryzen AI 400 PRO with Radeon graphics. HP says the Intel version supports up to 70 W max system TDP and the AMD version 35 W. Option lists come from the HP datasheets c09245898 (G2i 16) and c09252605 (G2a 16). No 16" QuickSpecs was found, so some fields are Unverified.

## Configurations
Datasheets list options, not fixed SKUs. Notebookcheck reports the 16" G2i on sale worldwide with Core Ultra X9 388H and Arc B390 graphics, up to 64 GB RAM and a 120 Hz panel.
