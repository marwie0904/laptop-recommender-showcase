# Lenovo ThinkPad P16v Gen 2 (2024)

## Best for
- **Rendering / 3D**: discrete GPU options (NVIDIA RTX 1000 Ada Generation Laptop GPU 6GB GDDR6, NVIDIA RTX 2000 Ada Generation Laptop GPU 8GB GDDR6, NVIDIA RTX 3000 Ada Generation Laptop GPU 8GB GDDR6, NVIDIA RTX 500 Ada Generation Laptop GPU 4GB GDDR6) plus up to 96 GB RAM.
- **Content creation**: color-accurate panel option (IPS, 100% DCI-P3, 100% sRGB).
- **Coding**: up to 96 GB RAM (SO-DIMM, upgradeable); a full keyboard with numpad.
- **Day-to-day**: HDMI, Thunderbolt/USB4, Ethernet for office docking and peripherals.
- **Dealbreakers**: the base 300-nit 45% NTSC panel is dim and washed out; pick a 100% sRGB option if available; heavy at 2.22 kg+.
